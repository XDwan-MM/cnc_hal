# 上台架验证清单（cnc_rt + HAL）

> 用途：**逐项划**。每条都写清"怎么验 / 什么算过 / 不过先看哪儿"。
> 配套：`HAL/docs/续接说明.md`（现状与未决）、`HAL/docs/仿真进HAL方案.md`（下阶段）。

## 0. 上台架之前（不做完别上动力电）

| # | 项 | 判据 |
|---|---|---|
| 0.1 | **用对档**：`cd 固件库/cnc_rt_1.27.0.1 && ./run.sh run` | 启动打印的线程名**不带"(调试)"**；`strings bin/cnc_rt \| grep -c CNC_RT_SIM_FAULT` = 0。（无参数的 `./run.sh` 走的是**仿真档**，电机不会动）|
| 0.2 | **先脱动力线 / 脱联轴器** | 第一轮只验通讯、身份、坐标方向，不给电机上电 |

| 0.4 | 备份参数域 + 记下版本 | 记下 `port_work` 与 `HAL` 的提交号、两个二进制的 sha256；**库 / 头 / RT / 固件包的 ABI 必须同一版（现在 7.2）**，混用会直接拒启 |
| 0.5 | 两档别混 | 仿真档（`cnc_rt_d`）在真机上：**坐标会跟着命令走、电机不动**，别拿它判断"轴动不动" |

## 0b. 驱动器侧必须先设的参数（蓝海华腾 VTS，手册附录 C）

这些**不在我们代码里**，但决定能不能动（尤其第 3 条）：

| 参数 | 应设成 | 为什么 |
|---|---|---|
| `P0-04` 使能选择 | `3`（EtherCAT 使能）| 不然主站使能命令不生效 |
| `P0-05` 速度指令选择 | `4`（EtherCAT 通讯给定）| 速度指令来源 |
| **`C2-00` EtherCAT 速度指令单位** | **`0`（rpm）** | **出厂默认是 `1`（pulse/s）**；设错则转速整体不对。若该驱动器只能 pulse/s：把 profile 的 `kSpeedUnit[]` 那一轴改成 `HAL_SPEED_PULSES_PER_S`（每转指令脉冲数由机床参数 `PAR_AX_PM_PULSE` 给，**不用改代码逻辑**）| 
| `C2-05` EtherCAT 通讯使能 | `1`（打开）| — |
| `C2-01` 位置指令平滑周期 | 与主站插补周期一致（我们 1000 us）| — |
| `C2-06` ECT 位置给定方式 | 按需（增量/绝对）| 影响位置语义 |
| `C2-03`/`C2-04` 速度齿轮比 | 先确认是不是 `1:1` | 不是 1:1 会再缩放一次转速 |
| `b0-01` 位置环指令选择 | `1`（EtherCAT 给定）| — |
| `PA-00`（个位）转矩指令选择 | `3`（EtherCAT）| — |
| `PA-01` 定位位置 / `b0-16` 偏移 | 按工艺（单位 puls）| **M19 定向到哪儿由驱动器参数决定** |
| `b0-11` 位置到达检测宽度 / `b0-29` 位置到达输出延时 | 按需 | 影响"定位完成"判定 |

## 1. 通讯与配置（还不动电机）

| # | 验什么 | 怎么验 | 判据 | 不过先看 |
|---|---|---|---|---|
| 1.1 | 主站起得来、从站齐 | 看启动日志 | 从站 0/1/2/3/4/5 全在（面板/IO/主轴/X/Y/Z），无启动超时 | EtherCAT 接线、`lib/cnc_hal/lib/devices.json`（`run.sh` 用 `CNC_HAL_DEVICES_JSON` 指它）|
| 1.2 | 轴绑定对 | 启动打印 `-- 轴绑定 --` | 四行都在、`[换算: 已装载]`；当量/enc_off/每转计数与参数域一致 | 参数域没填 → 显示"占位值"；`kBindings` 的从站号与实际接线 |
| 1.3 | 四轴身份对 | 用 `CNC_RT_DUMP=100,3000 ./run.sh run` 看快照 | 每轴 `身份=vendor/product/serial` 与**实际接线**一致 | ⚠️ **没有拓扑保护**：接错 HAL 不报，只能靠人对 |
| 1.4 | 主轴上限已装载 | 启动打印主轴那行 | `上限 xxxx rpm [上限: 已装载]`，值 = 参数域 `PAR_SPDL_MAX_SPEED` | 参数为空 → `[上限: 占位值]` |
| 1.5 | 台账清空 | 启动打印 `-- 未确认台账 --` | `无（可以开放运动）` | 显示"未确认"→ 参数域缺项（按轴 SCALING/ENC_OFF/ENCODER）|
| 1.6 | IO 映像段长 | 启动打印 | `X=.. Y=..` 字节，且 **≤ 512**；与配置的地址段吻合 | 超 512 是已知隐患（断言还没加）|

| 1.7 | **位置计数模式**（决定 `feedback_wrap`）| **不使能**，手动慢慢转主轴（或某根轴）**两圈以上**，盯驱动器面板 **`F0-17`（= `0x6064` 的值）** | `0 → 119999 → 0 → …`（每转归零）= **单圈模计数** → 配 `HAL_WRAP_MODULAR`；`0 → 119999 → 120000 → 239999 …`（一直累加）= **多圈/线性** → 配 `HAL_WRAP_LINEAR` | 配错的现象：MODULAR 配了多圈 → 角度**永远涨不过半圈**；LINEAR 配了模计数 → **每转过零跳一整圈**。我们 profile 现在给主轴配的是 **MODULAR + 每转 120000**，等这条确认 |

## 2. 坐标与当量（不使能，手推/盘车）

| # | 验什么 | 怎么验 | 判据 | 不过先看 |
|---|---|---|---|---|
| 2.1 | 方向与当量 | 盘车/手推一个**已知距离**（如 10 mm） | 界面坐标变化量对得上、方向对 | `PAR_AX_PM_MUNIT/PM_PULSE`（当量）、`command_invert/feedback_invert` |
| 2.2 | enc_off 语义 | 对比显示坐标与原始反馈 | 显示 = 原始 − `enc_off`（HAL 内部存 `−enc_off`，RT 传**不取反**）| `PAR_AX_ENC_OFF` |
| 2.3 | 进给轴速度口径 | 走一个已知进给，与**驱动器面板转速**对比 | 界面 mm/min ≈ 面板 rpm × 每转位移（每转位移 = 电子齿轮比分子，单位 mm） | 现在是这么算的（HAL 给 rpm，RT 乘每转位移）；对不上先回来核每转位移 |
| 2.4 | 主轴速度口径 | 低速 M3，对比驱动器面板/测速 | 一致（界面就是 rpm）| 主轴不再乘 60；对不上先查 `C2-00` 与 profile 的 `kSpeedUnit` |

| 2.5 | **主轴当量那一栏的单位** | 填完参数后手动把主轴转**整整一圈** | 接口/显示的角度正好变化 **360°** | ⚠️ **主轴的"电子齿轮比分子"要填 `360000`（千分之一度）**，填 `360` 会**小 1000 倍** —— RT 对它也做了 um→mm（÷1000）。离线台架参数就是这么填的（`set_axis(SP, 360000, 100000, 0, 120000)`）|

| 6.3 | 报警要不要开 | 按 6.2 的结论定 | 若"清掉后码会走"→ 可以开 `setAlarm(30+i)`；若"码留着"→ 只置标志 | 决定 = |
