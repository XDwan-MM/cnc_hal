从 clone 到现在，我们做了什么？

项目原本能扫描从站、构造 PDO 配置、下发并运行。我们在此基础上补了能力查询和一条离线 ESI 审核链路。两条链路目前还没有接通。

起点：clone 时已有的主站流程 读 EEPROM 身份和默认映射 → 组装 Slave_info → FPGA 主站下发配置 → 等待 OP 和握手 → HAL 绑定句柄

当前能确定什么？

离线报告能指出静态依赖是否有证据。它不能证明实际从站已接受配置。真实 FPGA 和从站还没有参与这轮验证。

说明：图中的“必需 PDO”指功能所需对象条目，例如位置轴的 6 项和主轴额外的 2 项；每台设备最终采用哪个 PDO 组合，还没有规划完成。ESI 离线工具使用 C++ 解析器和 Python 整理/审核，不在实时周期中运行。
